A selection of original projects, practical tools, and technical contributions. Projects are grouped by theme; each entry links to its source code and, when available, its live application.

## AI and intelligent systems

### [Agent Flow](https://github.com/squassina/agent-flow)

An environment to register LLM-based agents, chain them into flows, and track executions and token usage. The repository includes a full version built with Docker, FastAPI, Streamlit, and SQLite, as well as a static Lite version that runs in the browser.

- [Open Lite version](https://squassina.github.io/agent-flow/)
- [Source code on GitHub](https://github.com/squassina/agent-flow)

### [auto-model](https://github.com/squassina/auto-model)

A GitHub event router that selects AI models based on task requirements and the balance between capability and cost. It covers code reviews, documentation, issue triage, quick comments, and release notes, with GitHub Actions integration.

- [Source code on GitHub](https://github.com/squassina/auto-model)

### [PromptGen](https://github.com/squassina/PromptGen)

A web tool that turns plain-language answers into structured prompts for writing, planning, research, analysis, and coding. It includes guided examples, a quality indicator, and an editable generated prompt.

- [Open application](https://squassina.github.io/PromptGen/)
- [Source code on GitHub](https://github.com/squassina/PromptGen)

### [CV-JD-Match](https://github.com/squassina/CV-JD-Match)

A client-side tool that compares a resume with a job description using LLMs, provides a structured match analysis, and can generate a tailored resume and cover letter. Communication with the AI provider happens directly from the browser.

- [Open application](https://squassina.github.io/CV-JD-Match/)
- [Source code on GitHub](https://github.com/squassina/CV-JD-Match)

## Web products and tools

### [TechJobScout-lite](https://github.com/squassina/TechJobScout-lite)

A client-side tool for technology professionals to explore opportunities, assess job fit, and prepare STAR interview stories, with no backend or database.

- [Open application](https://squassina.github.io/TechJobScout-lite/)
- [Source code on GitHub](https://github.com/squassina/TechJobScout-lite)

### [XadrezMestre](https://github.com/squassina/XadrezMestre)

An open-source chess training application built with React and TypeScript, using the Stockfish engine to play against the computer.

- [Open application](https://squassina.github.io/XadrezMestre/)
- [Source code on GitHub](https://github.com/squassina/XadrezMestre)

### [Fator R Simulator](https://github.com/squassina/simulador-fator-r)

A web simulator for comparing Brazilian Simples Nacional Annex III and V scenarios, considering the Fator R ratio, owner compensation, DAS, INSS, and IRRF. Calculations run in the browser.

- [Open application](https://squassina.github.io/simulador-fator-r/)
- [Source code on GitHub](https://github.com/squassina/simulador-fator-r)

<blockquote>
**Note:** Fator R Simulator is an educational and planning tool. Results are estimates, tax parameters must be checked against current legislation, and decisions should be validated with a qualified tax professional.
</blockquote>

## Engineering, delivery, and collaboration

### [TPM Toolbox](https://github.com/squassina/tpm-toolbox)

A proposed project-delivery process combining Shape Up, Microsoft's Code With Engineering Playbook, and Agile practices. It explores planning, shaping, prioritization, technical spikes, build cycles, and reviews. The repository describes the material as an evolving proposal, not a finalized methodology.

- [Source code on GitHub](https://github.com/squassina/tpm-toolbox)

### [Documentation CI Pipeline](https://github.com/squassina/doc-pipeline)

A quality pipeline for technical documentation, combining Markdown standards, link checking, and writing clarity analysis. It demonstrates automation of engineering and documentation review practices.

- [Source code on GitHub](https://github.com/squassina/doc-pipeline)

### [AI-in-a-Box](https://github.com/squassina/AI-in-a-Box)

A collaborative collection of AI and machine learning accelerators and guidance, including Responsible AI, GenAI application security, MLOps, and Azure deployment patterns. This is a collaborative repository derived from a Microsoft Customer Engineers and Architects community initiative; it is not presented as an exclusively individual-authored project.

- [Repository and materials](https://github.com/squassina/AI-in-a-Box)
